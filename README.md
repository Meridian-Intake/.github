# Meridian Intake GitHub Repository

If you are viewing the repository directly, start here. If you are viewing the Meridian organization profile, GitHub renders the public profile from [`profile/README.md`](profile/README.md).

## Repository Purpose

This repository is intended to make Meridian's public GitHub presence easier to find, review, and maintain. It centralizes public-facing governance artifacts while keeping production systems, client data, credentials, and confidential implementation details out of public source control.

## Current Foundation

The current repository foundation includes:

1. A clear organization profile for Meridian Intake.
2. Community health files for contribution, security, support, and conduct.
3. PR and issue templates with privacy-aware checklists.
4. Public governance documents for roadmap, repository standards, and procurement questions.

## Best-in-Class Operating Artifacts

The repository now includes the high-impact operating artifacts identified in the roadmap:

- A concise security and privacy posture overview.
- A glossary for intake, routing, qualification, escalation, and evidence terms.
- Synthetic sample intake reviews and QA examples.
- Launch-readiness and escalation-policy templates.
- Metrics definitions and synthetic reporting examples.

## Data and Privacy Boundary

Do not commit secrets, credentials, client records, call transcripts, SMS conversations, patient data, privileged information, or confidential operational details to this repository. Use synthetic examples only.
