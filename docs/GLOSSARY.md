# Intake Glossary

This glossary standardizes Meridian's public language for controlled intake infrastructure.

| Term | Definition |
| --- | --- |
| Approved response | A message pattern reviewed and accepted for a workflow before use. |
| Audit trail | Reviewable records that show what happened, when it happened, and how a conversation was routed or resolved. |
| Boundary | A rule that prevents the system from making regulated, unsafe, or out-of-scope statements. |
| Escalation | A handoff to a human operator, licensed professional, client team, or designated reviewer. |
| Evidence | Logs, routing records, QA notes, timestamps, outcomes, and reporting definitions used to inspect intake performance. |
| First-response time | Time between a missed or delayed inbound event and the first approved follow-up. |
| Human oversight | A process in which people review, approve, monitor, or intervene in intake workflows. |
| Intake leakage | Demand that is missed, delayed, mishandled, unqualified, unrouted, or not followed up. |
| Intake review | A structured review of a conversation, workflow, or reporting period for quality, routing, outcomes, and risks. |
| Lead qualification | Structured collection of non-sensitive information needed to determine fit, urgency, next step, or routing path. |
| Missed-call recovery | Detecting a missed inbound call and initiating an approved follow-up process. |
| QA sampling | Reviewing a defined sample of intake activity against approved quality criteria. |
| Regulated professional judgment | Legal, medical, clinical, financial, or other licensed decision-making that must remain with qualified professionals. |
| Routing | Directing a conversation or lead to the right person, team, queue, calendar, or system. |
| Synthetic example | A fictional example that demonstrates format or process without using real client or caller data. |
| Workflow lifecycle | The stages of designing, approving, piloting, launching, reviewing, and improving an intake workflow. |
